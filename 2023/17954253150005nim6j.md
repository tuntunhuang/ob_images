## 首次登录卡在门外：网页授权没反应，或者弹窗报“Unexpected Issue”

第一次安装 Antigravity，或者为了凑额度切换 Google 账号时，90% 的人都会撞上这两堵墙：

**症状一：在客户端点登录，浏览器弹出来完成了 Google 账号授权，但切回 Antigravity 客户端毫无反应，连个 loading 动画都没有。**

这是因为浏览器授权成功后，需要往你电脑本地的回环地址（`localhost`）发一个回调凭据。
结果这个本地请求被你的网络环境半路截胡了，客户端监听器收不到回传数据，就一直在那儿傻等。

**症状二：浏览器授权成功，跳回客户端开始转圈，转完弹出一个红框：`There was an unexpected issue setting up your account.`**

这也是我当年死磕了一周、花掉 95% 时间才搞定的终极拦路虎。
核心原因是客户端底层真正负责联网的内部二进制进程，根本没走通你的网络通道；或者之前登录失败过多次，本地留下了脏缓存。

**怎么办？**

经过无数次折腾，目前**最稳、不用折腾全局虚拟网卡（免得电脑风扇狂转）、亲测次次成功**的方案只有两步：
1. 用一款 **P 开头的本地流量分流小工具**，按规则把发往 `localhost` 的请求拉回本地直连，并把 Antigravity 底层的几个内核进程精准绑定到你的本地端口上（Mac 用户记得顺手在系统网络设置里，把 IPv6 改成“仅本地链接”）。
2. 在 Mac 终端的 `~/.zshrc` 配置文件里，用 `alias` 命令给 Antigravity 绑定好本地端口。**配置好之后，永远不要双击桌面图标打开，每次都在终端输入 `Antigravity .` 启动。**

如果你之前已经尝试登录失败过很多次，重试前记得先彻底退出软件，在终端跑 3 行清理缓存的命令，把 `Local Storage`、`state.vscdb` 和 `globalStorage` 删干净。

## 以前用得好好的，某天突然提示“账号无权限（ineligible）”

明明网络环境没变，也是乖乖从终端启动的。
某天打开 Antigravity 准备干活，突然显示授权失败，直接跳到账号没有权限（`ineligible to use Antigravity`）的页面。
换用 Antigravity IDE 登录，照样报错。

**为什么会这样？**

不是你的配置坏了，是你的 **Google 账号关联地区自己跑偏了**。
这也是我踩过坑才知道的冷知识：Google 账号的关联地区会不定时在后台自动更新。
以前你的地区没问题，不代表它会一直没问题|||

**怎么办？**

1. 先去 Google 的条款页面（`https://policies.google.com/terms`）查一下账号当前的关联地区，看看是不是掉出了 Antigravity 的支持列表。
2. 如果真变了，直接去 Google 官方的地区更改申请页提交修改申请。

提交时有个小窍门：理由选“其他”，并且附上一段靠谱的英文说明（比如正在开发需要访问特定地区开发者工具的项目）。
我当时提交完，大概 1 个小时左右就收到了审核通过的邮件，重新登录立刻满血复活。

- **查看检查地区的方法、官方申请表单入口，以及可以直接复制粘贴的英文申请理由模板，看这篇（目前存活）：**
  → 《Antigravity，又是你小子》

## 被迫自动升级到 2.0 之后：Mac 登录报新错，Windows 直接黑屏

Antigravity 升级到 2.0（就是图标变成白色的那个版本）以后，连声招呼都不打就会在后台静默更新。
不仅把原本好好的客户端拆成了白色图标的 `Antigravity`（Agent Manager）和黑色图标的 `Antigravity IDE` 两个软件，还顺手送了 Mac 和 Windows 用户一人一个大礼包。

### 1. Mac 升级 2.0 后，突然登录报错，或者点右上角【Open IDE】没反应

如果你以前登录成功过，被偷偷升到 2.0 后突然登不上，大概率是因为 2.0 改了授权校验逻辑。
很多人电脑的 `/etc/hosts` 文件里，还留着古早时期配过的某云 IP（`119.28.87.227`）。以前相安无事，到了 2.0 就成了绊脚石。
只要在终端跑一行命令把这个报废 IP 从 `hosts` 里抹掉，再刷新一下 DNS 缓存就能正常进入了。

至于进去以后点右上角【Open IDE】毫无反应（甚至连报错都没有）……
那是因为你还得去官网单独下载安装黑色图标的 `Antigravity IDE`。

- **一键清理 hosts 报废 IP 的终端命令 + 2.0 家族折腾实录，看这篇（目前存活）：**
  → 《Antigravity又又又又登不上了》

### 2. Windows 自动升级到 2.0 后，登录报错，清缓存重启直接黑屏

Windows 这边更干脆。
连拔网线的机会都不给你，后台自动升完 2.0，先是登录报错；等你按老规矩清完缓存重启，它直接**全屏黑屏**，连个报错提示都懒得给。

**怎么办？**

把时间扔进黑洞去排查 2.0 的黑屏，纯属跟自己过不去。
我的解法很干脆：**卸载 2.0，装回 2.0 之前的最后一个稳定旧版本（1.23.2），然后彻底焊死自动更新的大门！**

安装旧版并登录成功后，第一时间先断网，进 `Editor Settings` → `Application` → `Update`，把第一项 `Enable Windows Background Updates` 的勾去掉。
只要它不强制更，旧版本用起来清爽得很。

- **如何关闭 Windows 自动更新的截图步骤，以及获取 1.23.2 旧版本安装包的方式（公众号回复“立刻还原”），看这篇（目前存活）：**
  → 《Windows折腾不动了，放弃Antigravity2.0》

## 老 Mac 升不动新版本，模型列表里刷不出 Argon 和 Neon 新模型

好不容易跨过九九八十一难登进去了，结果看着别人都在用 Argon、Hydrogen 甚至能跟 Astra 掰手腕的 Neon 模型，再看看自己的模型列表，可怜巴巴只有 4 个旧模型。

想用上新模型，首先要满足两个硬门槛：
1. 你的账号得是 **Google Pro 或 Ultra 账号**（通过 Google One 订阅的家庭账号也行，但印度的 Jio 那种免费送的不行，官方已经明确拒了）。
